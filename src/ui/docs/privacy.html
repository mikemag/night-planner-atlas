Privacy and credits

Your observing sites stay in your browser. Sharing them is a deliberate choice.

Your sites and data

Saved sites and preferences are kept in this browser’s local storage. Rebuildable calculations for saved sites are cached in this browser’s IndexedDB storage, including their coordinates. There are no accounts, analytics or remote coordinate lookups. The app loads its static assets from its own origin and calculations keep working after loading when the network is disconnected. Clearing browser site data removes saved favorites and preferences. If storage is unavailable, temporary changes are identified. Open Manage sites… → Browser data… to export or import sites and preferences, restore missing starters, or reset preferences while keeping your sites. Exported files include coordinates; keep a copy somewhere you control. Import is reviewed before replacing saved data, and the previous saved copy can be exported for recovery.

A shared link normally omits the whole site record. Choosing Include this site explicitly adds the reviewed name, coordinates, zone and optional elevation to the URL fragment. Anyone with that link can read them, and the URL can remain in browser history. Opening a link keeps its controls and included site temporary. Saving view settings and saving the site as a favorite are separate deliberate actions. Share links use readable fields after the #, with default settings omitted. The plan is carried in the link itself; there is no link-shortening service. Previously copied links still work.

The hosting provider handles ordinary static-file requests and connection metadata. Observing coordinates are not sent with those requests. A new offline visit or reload is not guaranteed.

Sun and Moon positions: Astronomy Engine 2.1.19 by Don Cross, MIT license.

Time-zone lookup: tzf-wasm 2.0.1 and tzf-rs, MIT. Boundaries: OpenStreetMap contributors, via timezone-boundary-builder and tzf-dist, data 2026e, ODbL 1.0. Download the matching boundary dataset (TZB, 4 MB).

Third-party software and data retain their own licenses. Private favorites and astronomical results are separate from the boundary dataset.

UI components: Bootstrap 5.3.8 by the Bootstrap Authors and Popper 2.11.8 by Federico Zivolo, both MIT. Their code and assets are bundled with the planner and work offline.
